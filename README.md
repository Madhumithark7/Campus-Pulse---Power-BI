# Campaign Pulse — Digital Marketing Performance Analytics

## Project Overview

Campaign Pulse is an interactive digital marketing analytics dashboard developed using Microsoft Power BI. It helps users explore campaign performance, compare revenue and spending, and monitor important marketing KPIs.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- CSV dataset

## Dashboard Features

- KPI cards for Total Spend, Total Revenue, Total Clicks, Total Conversions, Total Impressions, and Click-Through Rate (CTR).
- Monthly Revenue vs Spend trend analysis.
- Campaign-wise revenue comparison.
- Channel-wise spending distribution.
- Interactive Campaign Name and Platform slicers.

## Key Performance Indicators

- **CTR:** Total Clicks / Total Impressions
- **Conversion Rate:** Total Conversions / Total Clicks
- **Cost Per Click (CPC):** Total Spend / Total Clicks
- **Cost Per Acquisition (CPA):** Total Spend / Total Conversions
- **ROI:** (Total Revenue − Total Spend) / Total Spend

## Files Included

- `Digital Marketing Campaign Updated.pbix` — Power BI project file.
- `Campaign_Pulse_PowerBI_Dataset.csv` — dataset used in the dashboard.

## Dataset Note

The dataset contains simulated demonstration data for educational and portfolio purposes. The results do not represent actual business campaign performance.

## How to Use

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. If prompted, locate the CSV dataset and refresh the data.
4. Use the platform and campaign slicers to explore the dashboard interactively.

## Project Objective

To develop an interactive dashboard that presents digital marketing performance metrics clearly and supports data-driven campaign analysis.
